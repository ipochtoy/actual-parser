# 📦 Pochtoy Parsing - Order Parser Pro

**Версия:** 7.8.0
**Дата:** 2026-08-18

## 🚀 Описание

Расширение для браузера Chrome, которое парсит заказы с eBay, iHerb и Amazon и экспортирует их в Google Sheets.

## ✨ Основные функции

- **🛒 eBay** - парсинг заказов с eBay
- **🏥 iHerb** - парсинг заказов с iHerb  
- **📦 Amazon** - парсинг заказов с Amazon (с трек-номерами TBA)
- **🌙 Ночной обход** - последовательный проход шести кабинетов в 23:00 по Питтсбургу
- **📊 Export** - экспорт в CSV и Google Sheets

## 🌙 Как работает ночной обход

- Стадии идут строго по очереди: `iHerb → eBay → Amazon → done`.
- Проверяется точный состав: 3 кабинета iHerb, 1 eBay и 2 Amazon.
- После перезапуска Chrome или service worker обход продолжает тот же кабинет и попытку.
- Карточки треков завершаются в своём кабинете и не съедают лимит времени парсера.
- Финальный зелёный статус ставится только после точного состава кабинетов и подтверждённой выгрузки в Google Sheets.
- Единственная ручная проверка — iHerb Press & Hold: обход безопасно останавливается, сохраняя очередь и вкладку.

Amazon использует последние три месяца заказов, до 20 страниц на кабинет. Все переходы страницы и смены аккаунта привязаны к точной вкладке и поколению ночного прогона.

## 📋 Как использовать

1. **Установите расширение** в Chrome
2. **Откройте** любой из поддерживаемых сайтов
3. **Нажмите** кнопку расширения
4. **Выберите** нужный вариант парсинга
5. **Скопируйте** данные в Google Sheets

## 🐛 Решение проблем

### Amazon не парсится:
1. Попробуйте кнопку **"📦 Amazon (1 страница)"**
2. Откройте консоль браузера (F12) для логов
3. Убедитесь, что вы на странице заказов Amazon

### Parse All не работает:
1. Проверьте, что все сайты открываются
2. Дождитесь загрузки всех вкладок
3. Проверьте консоль на ошибки

### Данные не появляются:
1. Проверьте кнопку "Copy for Google Sheets"
2. Убедитесь, что парсинг завершился
3. Попробуйте экспорт CSV
