## v7.9.0 — одна отправка = ВСЕ её товары (2026-09-02)

**Что было.** Заказ Amazon 114-4364449-9800232: одна отправка, четыре куклы. Скринер
записал в лист ОДНУ строку («Valentina & Cinder», qty 1), робот описи честно пересказал
лист складу — «В посылке 1 товар». Склад пришил одну вещь из четырёх.

**Почему.** Товар отправки искали по `itemId` из ссылки кнопки Track — она указывает на
один товар. Разбор всей рамки доставки стоял ПОЗЖЕ и включался только через
`if (!productLink)`, то есть при удачном `itemId` не выполнялся никогда. Саму рамку
ловили в том числе по `.a-box` — у Amazon этот класс висит и на рамке одного товара.
Пометки «состав не разобран» не было вовсе, а `extractQuantityFromDOM` при неудаче
возвращал `"1"`, то есть выдумывал количество.

**Что стало.**
- Новый файл `shipment-scope.js` (подключён в manifest ПЕРЕД `content-amazon.js`):
  `shipmentScope()` — самая маленькая рамка вокруг кнопки, где ровно одна кнопка
  отправки и есть товары; `collectShipmentProducts()` — все позиции рамки,
  сгруппированные по рамке позиции, а не по ASIN (пять банок одного товара = пять
  позиций).
- В `content-amazon.js` рамка отправки разбирается ПЕРВОЙ и всегда;
  `trackBtn._allProducts` присваивается всегда массивом; `itemId` из ссылки стал
  проверкой; ветка «подъём на 7 уровней» удалена; `.a-box` из селектора рамки убран.
- Пометка «состав не разобран» уходит в журнал (`sendLog`) и в поля
  `composition_parsed` / `composition_reason`; причины: `scope-multi-track`,
  `itemId-not-in-box`, `a-fallback`, `d-fallback`, `empty-qty`.
- `extractQuantityFromDOM` больше не выдумывает `"1"`: рамку позиции опознали и значка
  нет — одна штука; рамку опознать не удалось — `null`, то есть пустой qty.
- Лист получил колонки **J** (`parser|<время>`) и **K** (`состав не разобран`). Колонку F
  не трогаем: её затирает `markRowsDone`.
- Робот описи при пометке или пустом qty пишет «⚠️ Состав отправки не разобран — сверить
  по кабинету магазина. Известные позиции:» и НЕ печатает число позиций; `content-pochtoy.js`
  сравнивает с прошлой описью и дописывает «(состав уточнён: было N, стало M)» либо
  «⚠️ расхождение с прошлой описью: было N».
